# Sample volumes

Two small artifact-free complex tomograms for demonstrating and testing the inference code:

| File | Tissue | Shape |
|---|---|---|
| `optic_nerve.npy` | Optic nerve | (Z, X, Y) = (512, 512, 10) |
| `salmon_skin.npy` | Salmon skin | (Z, X, Y) = (512, 512, 10) |

Axes are (Z, X, Y): depth, fast-scan, slow-scan. A volume can be stored either as a complex array of shape (Z, X, Y) or as a real array of shape (Z, X, Y, 2) whose last axis holds the real and imaginary parts.

These volumes are placed here by the authors; they are not generated by any script in this repository.
